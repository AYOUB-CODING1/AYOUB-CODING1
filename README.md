"$ whoami"

I'm Ayoub El Maadi, an independent cybersecurity researcher and founder of "Cayvora" (https://cayvora.com).

My work revolves around understanding how software behaves, identifying security weaknesses, and exploring attack surfaces across modern applications.

I focus primarily on:

- Web Application & API Security
- Android Application Reverse Engineering
- LLM Security Research
- Vulnerability Discovery & Responsible Disclosure
- Security Tooling and Automation

Beyond cybersecurity, I'm interested in the intersection of Mathematics, Artificial Intelligence, and Computer Science.

I believe in learning through experimentation, independent research, and building things that solve real problems.
